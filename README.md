# Tracker Per Hour

A lightweight World of Warcraft addon that shows how much gold, how many kills and how much experience you earn per hour. Start a session when you begin farming or questing, and stop or reset it whenever you like.

> **For WoW Forever only.** This addon is built for the WoW Forever client and is not supported on Retail, Classic Era or other versions of the game.

## Features

- **Per-hour rates** for gold, kills and experience over a session you start, stop and reset.
- **Rolling gold and XP rates** that cover the last hour, so they follow your current pace.
- **Session totals**: gross gold gained, net gold, kill count, and estimated time to your next level.
- **Pet kills** can count as your own (optional setting).
- **Two window styles**: minimalist and classic.
- **Minimap button**: left-click shows the tracker, right-click opens settings, and the tooltip shows your current rates.

## Slash commands

| Command       | Action                     |
| ------------- | -------------------------- |
| `/tph`        | Show or hide the tracker   |
| `/tph start`  | Start the session          |
| `/tph stop`   | Stop the session           |
| `/tph reset`  | Reset the session          |
| `/tph open`   | Open the tracker window    |
| `/tph config` | Show or hide settings      |

`/trackerperhour` works as an alias for `/tph`.
